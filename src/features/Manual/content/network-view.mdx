zooming and panning, the buttons at the bottom right of the view, and the

## Network View

The network view draws the current network. Click a node or edge to select
it; Shift-drag to select several at once. Scroll to zoom and drag the
background to pan.

Four buttons at the bottom right of the network view act on the network:

| Button | What it does |
| --- | --- |
| <UiIcon name="apply-layout" label="Apply default layout button" /> Apply default layout | Runs the default layout. Change the default in **Layout → Settings...**. |
| <UiIcon name="fit" label="Fit button" /> Fit network to the window | Zooms so the whole network fits in the view. |
| <UiIcon name="open-in-cytoscape" label="Open in Cytoscape button" /> Open in Cytoscape | Sends the network to the Cytoscape desktop application. It needs Cytoscape Desktop running on your computer (default port: 1234), and it does not work in Safari. The first time, Cytoscape Web explains the browser's permission prompt for reaching your computer. |
| <UiIcon name="share" label="Share button" /> Share | Copies a link to the network, including the current view and selection, to your clipboard. It works only for networks saved to NDEx; save a local network to NDEx first. |

## Cell View

When the current network is a hierarchy, two tabs appear at the top of the
network view: **Tree View**, the network drawn as nodes and edges, and
**Cell View**, the hierarchy drawn as nested circles (circle packing):

<Screenshot id="cell-view" />

In Cell View, each circle is a system. A system can contain smaller
systems, much like Russian nesting dolls. Click a circle to select that
system. Scroll or double-click to zoom in; the labels of smaller systems
appear as you zoom. Click the background to clear the selection.

When you select a system, its interaction network appears in the **Sub
Network Viewer** in the right panel. The Sub Network Viewer tab is there only
while the current network is a hierarchy:

<Screenshot id="sub-network-viewer" />

Open the right panel with the arrow button
<UiIcon name="open-panel" label="Open panel button" /> at the
right edge of the window, and close it with the arrow at the top of the
panel. Switching to a hierarchy opens it. Switching from a hierarchy to
another network closes it, unless a tab added by an app is selected: that
tab stays open. Selecting genes in the Sub Network Viewer highlights them in the
Cell View.

When the hierarchy's interaction data comes from more than one source, a
filter below the Sub Network Viewer lets you show or hide each source.

Hierarchy networks also add the **LLM QUERY** tab to the side panel. See
[Analysis](menus#analysis).
