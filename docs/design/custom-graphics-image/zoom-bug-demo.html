Cytoscape.js Image Property Exploration

Scroll your mouse wheel in the right pane to zoom in and out. Notice the behavior of the background images in each scenario.

Context: The Cytoscape.js Zoom Offset Bug (Nodes 1-3)

Nodes 1, 2, and 3 explore an observed issue in the Cytoscape.js canvas rendering engine regarding the background-position property. When a background image's bounding box is smaller than the node, and it is offset to the center (using either percentages like 50% or explicit pixels), the image visibly slides off its anchor point during canvas zoom events.

The SVG URL Catch-22: This bug specifically traps SVG images loaded via external URLs. Because browser Canvas CORS security forbids us from wrapping external URLs in our "SVG Wrapper Hack", and because many external SVGs lack intrinsic pixel dimensions (causing Cytoscape to stretch them violently if we don't explicitly size them), we are forced to manually size and center them using background-position. Doing so immediately triggers this zoom bug, leaving URL SVGs with no viable workaround.

Probable Cause: In the internal Cytoscape.js 2D canvas drawing pipeline, the math used to calculate the relative image offset does not scale accurately with the canvas transformation matrix during a zoom event. As the camera zooms, the calculated offset scales at a different rate than the node's dimensions, causing the image to "drift" away from the center.

1. Baseline (Stable, but stretched)

Image Type: SVG | Source: Data URI

Settings: width: 200px, height: 50px, fit: contain

Desired: Centered image that preserves aspect ratio.

Result: Cytoscape forces the image to perfectly stretch to the 200x50 bounds (distorting SVGs missing width/height attributes). No zoom bug.

2. The Percentage Zoom Bug

Image Type: SVG | Source: Data URI

Settings: width: 50px, height: 50px, position-x: 50%

Desired: Perfect 50x50 centered square.

Result: Image slides dramatically off-center when zooming due to an internal Cytoscape percentage scaling bug.

3. The Pixel Zoom Bug

Image Type: SVG | Source: Data URI

Settings: width: 50px, position-x: 75px

Desired: Bypass percentage bug with explicit pixel center.

Result: Still slides off-center when zooming. Cytoscape fails to scale explicit pixels to zoom context properly.

4. The SVG Wrapper Hack

Image Type: SVG | Source: Data URI

Settings: Raw SVG nested inside an invisible 200x50 viewBox wrapper to natively pad aspect ratio.

Desired: Perfect square without zoom sliding.

Result: Inner image remains perfectly proportioned. Cytoscape sees a 200x50 bounding box, so offset is 0, completely avoiding the zoom bug.

5. External PNG (Baseline)

Image Type: PNG (Raster) | Source: External URL

Settings: width: 200px, height: 50px, External PNG.

Desired: Preserve PNG aspect ratio.

Result: The explicit width/height forces Cytoscape to stretch the PNG, completely destroying its native aspect ratio.

6. Contain Only (No width/height)

Image Type: PNG (Raster) | Source: External URL

Settings: width: auto, height: auto, fit: contain

Desired: Automatically letterbox external raster images.

Result: By omitting explicit bounds, Cytoscape correctly utilizes the PNG's intrinsic aspect ratio and letterboxes it without triggering the zoom bug.

7. Native Cy.js Overlay

Image Type: SVG | Source: Data URI

Settings: width: 50px, clip: none, position-x: 175px

Desired: Draw image completely outside node bounds.

Result: Image suffers from the zoom slide bug. Also, the browser canvas physically crops the rendering to the 50x50 bounding box, cutting the image in half.

8. SVG Wrapper Overlay

Image Type: SVG | Source: Data URI

Settings: Wrapper hack, but inner SVG is outside 200x50 viewBox with overflow="visible".

Desired: Draw outside bounds without zoom bugs.

Result: Perfectly fixes the zoom bug, but the browser canvas still hard-crops the rendering exactly at the 200x50 bounding box.

9. Oversized Bounds Overlay

Image Type: SVG | Source: Data URI

Settings: width: 300px, height: 150px (larger than node). Wrapper SVG centered.

Desired: Overlay image completely outside node.

Result: The massively oversized bounding box gives the SVG enough canvas real-estate to draw anywhere outside the node. Perfectly avoids zoom bugs because the Wrapper SVG matches the oversized bounds.
